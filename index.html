03 Method Open source Sheet 03 / 04

A win only counts when the game says so.

No self-reported scores. Each run is played live and checked against the game's own objective. Read the full method.

  1. The game shares its state

    Units, positions and objectives are read from the live game and turned into a list of legal moves.

  2. The model makes the call

    The decision model picks one move from the list. No chat and no free text, only a decision.

  3. The outcome is verified

    The run is scored against the game's objective, then published with its evidence, win or lose.
